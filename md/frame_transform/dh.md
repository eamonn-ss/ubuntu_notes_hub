#  DH参数（Denavit-Hartenberg 参数）

## DH参数的目的

在机器人学中，我们经常需要描述机械臂各个连杆之间的空间位姿关系（位移+旋转）。DH参数是一种标准化的方式，用4个参数来描述两个关节坐标系之间的变换关系。

## DH参数的定义（标准DH）

对于机械臂中任意两个相邻连杆 i 和 i+1，使用 4 个参数描述它们之间的变换：

| 参数名  | 符号         | 含义                                         |
| ---- | ---------- | ------------------------------------------ |
| 关节角  | $\theta_i$ | 沿 $z_{i-1}$ 轴旋转，使 $x_{i-1}$ 与 $x_i$ 对齐（旋转） |
| 连杆长度 | $a_i$      | 沿 $x_i$ 轴平移，使 $z_{i-1}$ 与 $z_i$ 对齐（平移）     |
| 连杆扭角 | $\alpha_i$ | 沿 $x_i$ 轴旋转，使 $z_{i-1}$ 与 $z_i$ 对齐（旋转）     |
| 连杆偏距 | $d_i$      | 沿 $z_{i-1}$ 轴平移，使原点重合（平移）                  |

“绕 Z 转 𝜃，沿 Z 移 𝑑，沿 X 移 𝑎，绕 X 转 𝛼”

## DH变换矩阵的形式

每一组 DH 参数构造一个 4x4 齐次变换矩阵 𝐴𝑖



## 上下标

| 符号      | 含义              | 解读               |
| ------- | --------------- | ---------------- |
| $T_B^A$ | 坐标系 B 到 A 的变换矩阵 | 把 B 系下的点变换到 A 系下 |
| 上标 A    | **目标坐标系（to）**   | 你想“变到哪”          |
| 下标 B    | **源坐标系（from）**  | 你“当前在哪”          |
