## 角色术语

| 名称 | 英文 | 含义 | 常见别名 | 角色 |
| --- | --- | --- | --- | --- |
| 源点云 | Source point cloud | 需要被变换以对齐的点云 | moving / input cloud | 主动、被移动 |
| 目标点云 | Target point cloud | 对齐时保持不动的参考点云 | fixed / model cloud | 被动、基准 |
| 参考点云 | Reference point cloud | 配准基准坐标系所在点云（常即目标点云，也可能是全局地图） | base / world reference | 坐标系锚点 |

## 配准在做什么

目标点云留在参考系中不动；源点云通过刚体变换 \((R, t)\) 被搬到同一参考系。两者对齐后，配准成功。

本质：求变换 \(T\)，使源点云变换后与参考（通常是目标点云）对齐。

常见写法：

\[
\min_{R,t} \sum_i \| R\,x_i + t - y_i \|^2
\]

其中 \(x_i\) 为源点，\(y_i\) 为对应目标点（对应关系可由最近点、特征匹配等得到）。

## 常见算法层次（概念）

| 类型 | 例子 | 特点 |
| --- | --- | --- |
| 粗配准 | FPFH + RANSAC、全局特征 | 给初值，抗大偏差 |
| 精配准 | ICP / GICP / NDT | 依赖初值，迭代细化 |

实操时先粗后精，并注意尺度、密度、部分重叠与外点。
