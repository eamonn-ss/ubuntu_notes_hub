# 点云

## 点云配准(point cloud registration)

1. 
| 名称   | 英文                        | 含义                                          | 常见别名                         | 角色                   | 状态 |
| ---- | ------------------------- | ------------------------------------------- | ---------------------------- | ----------------------------- |-----|
| 源点云  | **Source point cloud**    | 需要被“移动”（变换）以对齐的点云                           | moving cloud / input cloud   | 主动的、被移动的一方 | ​动态的​​，需要被变换 |
| 目标点云 | **Target point cloud**    | 作为对齐“参考”的点云，保持不动                            | fixed cloud / model cloud    | 被动的、作为基准的一方 | 静态的​​，保持不动 |
| 参考点云 | **Reference point cloud** | 一个通用术语，通常指配准的“基准”坐标系所在点云（可能就是目标点云，也可能是全局地图） | base cloud / world reference |   |   |

2. 目标点云保持在参考系中不动，源点云通过变换（R,t）被搬运到目标点云所在的参考坐标系中，两者重合后，表示配准成功

3. 点云配准的本质是——
找到一个变换，使源点云在参考点云（通常是目标点云或全局地图）坐标系下对齐。
